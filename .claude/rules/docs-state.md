# Documentation State Rules

- `CURRENT_PROJECT_STATE.md` describes verified implementation, not aspirations.
- `TASK_BOARD.md` must distinguish TODO from DONE and LOCAL_VALIDATION_REQUIRED.
- `DEVLOG.md` is append-oriented; do not erase useful history.
- If documentation conflicts with live Unreal state, update documentation after local verification.
- Do not silently convert design ideas into implemented facts.
