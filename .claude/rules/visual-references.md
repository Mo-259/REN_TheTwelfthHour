# Visual Reference Rules

Applies to any task involving character art, weapon art, environment art, materials, or visual replacement (including greybox → art mesh swaps).

- Read `ProjectDocs/References/REFERENCE_MANIFEST.md` first.
- If the manifest lists a master image for the subject, that master is the **visual authority**.
- If there is no manifest, or no master for the subject: use placeholders only, and label them `TEMP_PLACEHOLDER — NOT VISUAL AUTHORITY` in the asset description and in docs. For level-placed placeholder characters, also add an editor-only TextRender or Billboard with that text (Hidden in Game).
- Never redesign a locked character to match a template asset.
- Never make final visual decisions based on `Variant_Combat` or Third Person mannequins.
- Status on 2026-09-30: `ProjectDocs/References/` is **not yet in the repository**, so every character and weapon visual is `TEMP_PLACEHOLDER`.
