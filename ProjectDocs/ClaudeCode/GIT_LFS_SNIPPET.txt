# Git LFS snippet — inspect existing .gitattributes before merging

Recommended if the repository does not already track these paths with LFS:

ProjectDocs/References/**/*.png filter=lfs diff=lfs merge=lfs -text
ProjectDocs/References/**/*.jpg filter=lfs diff=lfs merge=lfs -text
ProjectDocs/References/**/*.jpeg filter=lfs diff=lfs merge=lfs -text
ProjectDocs/SourceOfTruth/**/*.pdf filter=lfs diff=lfs merge=lfs -text

Do not overwrite the repository's existing `.gitattributes`.
