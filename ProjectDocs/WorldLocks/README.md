Workflow:

1. Open the intended Unreal level.
2. Export baseline.
3. Commit the JSON.
4. Make intentional level changes.
5. Validate.
6. Review all differences.
7. If approved, export a new baseline and update `docs/DEVLOG.md`.

Do not hand-edit transform values merely to make validation pass.
