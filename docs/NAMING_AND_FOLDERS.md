# REN — Naming & Folder Conventions

## Unreal asset prefixes

Use consistently:

- `BP_` Blueprint Actor / general Blueprint
- `BPI_` Blueprint Interface
- `BPC_` Blueprint Actor Component
- `WBP_` Widget Blueprint
- `IA_` Input Action
- `IMC_` Input Mapping Context
- `ABP_` Animation Blueprint
- `AN_` Anim Notify
- `AM_` Anim Montage if project convention adopts it
- `M_` Material
- `MI_` Material Instance
- `MF_` Material Function
- `T_` Texture
- `SM_` Static Mesh
- `SK_` Skeletal Mesh
- `NS_` Niagara System
- `S_` Sound asset
- `SC_` Sound Cue
- `LS_` Level Sequence
- `L_` Level / Map
- `E_` Enum
- `ST_` Struct
- `DT_` Data Table
- `DA_` Data Asset

Do not introduce new prefixes casually.

## Actor labels generated by tools

Editor-generated REN actors should start with:

`REN_`

Examples:
- `REN_Sarcophagus`
- `REN_Trigger_ShadowClue`
- `REN_Light_DuatReveal`

This lets validation/cleanup scripts operate safely without touching unrelated actors.

Sprint sub-prefixes (still `REN_`-prefixed so world-lock covers them):
- `REN_INT_` — hand-placed interactable Actors (e.g. `REN_INT_ExitDoor`)
- `REN_NEC_` — Necropolis builder output (cleanup scoped to this prefix)
- `REN_GW_` — Gate of the West / Face-Eater arena builder output (cleanup scoped to this prefix)

Warning: Tomb builder v3 cleans up *all* `REN_` actors; it is guarded to refuse after the Tomb baseline exists.

Sprint levels:
- `L_REN_Slice` — persistent level (no gameplay geometry)
- `L_Tomb_Blockout`, `L_Necropolis_Blockout`, `L_GateWest_Blockout` — sublevels

## Script naming

Editor Python:
`REN_<Purpose>.py`

Examples:
- `REN_Tomb_Opening_Greybox_Builder_v3.py`
- `REN_Export_WorldLock.py`
- `REN_Validate_WorldLock.py`

## Versioning

Do not encode versions in final production Unreal asset names.

Version suffixes are acceptable for temporary editor scripts while iterating.
